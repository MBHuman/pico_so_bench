# Бенчмарк сравнения веток на производительность

Используется для сравнения нескольких веток по производительности. Для сравнения используется проведение основных операций tarantool:

## Файлы бенчмарков

Каждый файл `bench_*.lua` рассматривает отдельный случай использования. Например движок `memtx`. Результаты должны сохранятся в CSV таблицу для последующего анализа. Каждый бенчмарк должен быть расчитан на использование коэффициента SCALE, чтобы с помощью одного коэффициента можно было задать случай с большим объемом данных. Сейчас рассматриваются следующие случаи:

| Бенчмарк | Что происходит | Можно сравнить с другими ветками |
| ----------------|--------------------------------------------------| ------------|
| bench_memtx.lua | Рассматривается проведение операций: `insert`, `get`, `select`, `update`, `replace`, `delete` | Да (основной функционал) |
| bench_vinyl.lua | Операции аналогичные bench_memtx.lua | Да(основной функционал) |
| bench_sort_order.lua | Оценивается скорость проведения операций при индексах с sort_order. Рассматривается поведение: `insert`, `select`, `select reverse`, `update`, `replace`, `delete`. Нужно для определения падения производительности при росте данных | Нет (код запустится, но бенчмарк будет не информативным)|

## Скрипты запуска

Скрипты `run_*.sh` делают сдедующее:

- `run_all.sh` - запускает все бенчмарки (задаются внутри)
- `run_repeated.sh` - запускает `run_all.sh` N раз с обозначенным SCALE
- `run_repeated_scaling.sh` - запускает `run_repeated.sh` с набором SCALE параметров. Например 10 20 30 запустит 3 варианта с разными скейлами N раз
